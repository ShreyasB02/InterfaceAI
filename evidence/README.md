# Evidence

Real runs of the system, end to end: an LLM discovers a flow, the flow is
saved as a reviewed artifact, and the artifact is replayed with no model.

- **[`INDEX.md`](./INDEX.md)** lists 17 scenarios with the folder for each.
  It is generated by `scripts/make_evidence.py`, which runs the real CLIs in
  order and checks that each run ended as expected.
- The table below adds three runs where **a person**, not a script, took
  over the live session.

Each run folder holds `log.jsonl` (the structured, redacted trace: every
decision with the model's stated `reason`, the provider and model that
answered, every step, escalation and outcome), `screenshots/`, and
`artifact.json` (discovery) or `result.json` (replay). A failed replay also
has `failure_dom.html`. `control.json` is the handoff channel's final state.

The artifacts these runs produced and replayed are in
[`../artifacts/store/`](../artifacts/store/).

## The through-line

1. **Discovery** (`INDEX.md` rows 1 and 11): a real model drives the mock
   banking console and records `lookup_member_balance` and
   `open_sub_account`.
2. **Review**: each is approved by a named reviewer. Row 10 shows an
   unapproved draft being refused.
3. **Deterministic replay** (rows 2–9, 12–16): the approved artifacts run
   with no model, once per outcome class:

| Outcome class | Rows |
|---|---|
| Success, including a different member than the one recorded | 2, 3, 12 |
| Business outcome: not found, permission denied, validation | 4, 13, 14 |
| Recoverable condition handled, then success | 5, 6 |
| Hard failure with step / expected / observed, screenshot, DOM snapshot | 7 |
| Blocked by policy before acting | 8 |
| Refused: artifact not approved | 10 |
| Human escalation: confirmed and resumed; cancelled | 15, 16 |
| Interrupted by an operator | 9 |

4. **Human in the loop during discovery** (row 17, and the first by-hand
   run below): the goal withholds a decision, the model calls
   `request_human`, an operator acts on the same live session, and the
   model carries on. What the operator did is recorded as artifact steps.

## What was real and what was scripted

- **The model was always real.** No discovery here used a scripted model
  (that exists only in the test suite). Gemini was overloaded during these
  runs, so most were served by `google/gemini-2.5-flash` through OpenRouter
  after logged retries and a failover; the first by-hand run was served by
  `gemini-3.8-flash` directly.
- **Every replay drove a real browser** against the target app, with no
  model.
- **"Scripted operator"** (rows 9, 15, 16, 17) means a script stood in for
  the person's *decisions*. It attaches to the same live browser over CDP
  from a separate connection, as a person's browser would. The pause, the
  control transfer, the observation of what was done, and the resume are
  the same code path the by-hand runs used.
- **The data is fabricated.** The target is this repo's mock app; names and
  balances in screenshots and replay outputs are invented.

## Things a reader may notice

- **Member names and balances appear in replay `result.json` outputs.**
  Those are the capability's declared outputs. They do not appear in logs,
  artifacts, or DOM snapshots; a member's name shows there as
  `[REDACTED-member_name]`.
- **`open_sub_account` v3.0.0 is `rejected`.** It came from the first
  by-hand discovery: while I held the session I re-opened the form, and
  that redundant click was faithfully recorded as a step. The run is kept
  as evidence of the handoff; the artifact was rejected in review and v4
  recorded.
- **The three by-hand runs predate the `reason` argument** on tool calls, so
  on turns Gemini served, their `decide` lines have no stated reason. Every
  run in `INDEX.md` has one on every decision.
- **Version numbers.** `lookup_member_balance` 1.0.0 is the discovery
  output and 1.1.0 adds the known outcomes; likewise `open_sub_account`
  4.0.0 and 4.1.0. Each x.1.0 is the approved one.

## Regenerating

With the target app running and a provider key in `.env`:

```bash
python scripts/make_evidence.py --reviewer "Your Name"
```
